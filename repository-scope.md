# Repository Scope

This repository is the public research-artifact home for **PRAMANEX TRACE: Evidence Is the Control Plane**.

The repository is intentionally structured to keep five evidence classes separate:

1. **Publication evidence** - the DOI-bearing paper and its declared architecture.
2. **Architecture figures** - visual representations of the evidence-to-decision control plane and trust boundaries.
3. **Validation specifications** - paper-grounded normal and adverse test cases.
4. **Reproducibility requirements** - what a future implementation must preserve to support stronger claims.
5. **Implementation evidence** - not currently claimed unless executable artifacts and observed tests are added later.

The repository must not be used to imply production deployment, customer validation, independent security certification, or organization-specific regulatory acceptance that has not been demonstrated.
