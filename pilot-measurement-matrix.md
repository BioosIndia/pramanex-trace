# Pilot Measurement Matrix

| Dimension | Required denominator / evidence | Stop condition |
|---|---|---|
| Authority/source | Approved source + purpose + reconstructable version | Authority ambiguity |
| Candidate quality | Grounded material fields + explicit unknown/conflict states | Unsupported critical field |
| Human authority | Approve / revise / request evidence / reject with rationale | Approval bypass |
| Security/privacy | Negative access tests + absence of restricted disclosure | Critical exposure |
| Reliability | Visible retry, recovery and terminal states | Silent failure or irrecoverability |
| Value | Prespecified baseline + observation period + review/control burden | Unmeasured benefit |

## Evidence maturity classes

| Class | Evidence required | Claim boundary |
|---|---|---|
| Architecture | Public source / design rationale | Supports architectural reasoning only. |
| Implementation | Controlled repository + executable artifact | Supports runnable implementation claims. |
| Functional performance | Frozen task-specific tests + failure analysis | Supports narrow measured performance claims. |
| Security posture | Assessment + remediation record | Supports assessed security posture. |
| Customer outcome | Authorized pilot + observed baseline | Supports context-specific operational outcomes. |
| Validated use | Organization-specific qualification + approval | Supports validated use in the deploying organization. |
