# Adverse Scenario Control Matrix

| Scenario | Required evidence/state | Control outcome |
|---|---|---|
| Official source unavailable | Capture attempted retrieval and source-health failure; preserve the last known baseline as historical evidence. | Do not report no change. |
| Same title, changed lifecycle status | Retain both snapshots; compute affected impact candidate. | HOLD. |
| Valid document, wrong cited passage | Resolve citation to stored version and relevant location. | Fail the material claim. |
| Reviewer authority revoked while paused | Recheck authorization at disposition. | Reject the old action. |
| Source changes after approval | Calculate dependent candidates; retain prior history. | Require revision-bound review. |

Every adverse scenario should produce expected and actual evidence at both API and UI layers in a future implementation.
